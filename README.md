# Pet Store

## Опис проєкту

Pet Store — це веб-додаток інтернет-магазину для домашніх тварин, який надає зручний інтерфейс для перегляду та покупки товарів для домашніх улюбленців.

## Функціональність

- **Головна сторінка** з різноманітними секціями:
  - Hero секція з основним заголовком
  - Промо-банери
  - Каруселі з товарами (тварини, трендові товари, нові надходження)
  - Секція безпеки
  - Промоції та акції
  - Відео-промо
  - Відгуки клієнтів
  - Каталог кормів

- **Сторінка продукту** з детальною інформацією:
  - Галерея зображень з можливістю перегляду
  - Детальна інформація про продукт
  - Додавання товарів до кошика
  - Керування кількістю товару

- **Кошик покупок**:
  - Модальне вікно кошика
  - Додавання/видалення товарів
  - Оновлення кількості товарів

## Технології

- **HTML5** — структура сторінок
- **CSS3** — стилізація компонентів
- **JavaScript (ES6+)** — інтерактивність та логіка
- **HTMX** — динамічне завантаження контенту без перезавантаження сторінки

## Структура проєкту

```
pets-store/
├── api/                    # API дані (JSON)
├── assets/                 # Зображення та інші ресурси
├── css/                    # Стилі компонентів
├── js/                     # JavaScript модулі
├── *.partial.html          # Часткові HTML компоненти
├── index.html              # Головна сторінка
└── homepage.html           # Сторінка продукту
```

## Запуск проєкту

1. Клонуйте репозиторій або завантажте файли проєкту
2. Відкрийте `index.html` у веб-браузері або використайте локальний сервер

Для запуску з локальним сервером (наприклад, за допомогою Python):

```bash
# Python 3
python -m http.server 8000

# Або за допомогою Node.js (якщо встановлено http-server)
npx http-server
```

Потім відкрийте браузер і перейдіть за адресою `http://localhost:8000`
