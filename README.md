## 📖 Опис проєкту

**Pet Store** — це повнофункціональний веб-додаток інтернет-магазину, розроблений для продажу товарів для домашніх тварин. Проєкт демонструє сучасні підходи до розробки frontend-додатків з використанням модульної архітектури та технологій динамічного завантаження контенту.

Проєкт реалізує основні функції e-commerce платформи: перегляд каталогу товарів, детальну інформацію про продукти, кошик покупок та інтерактивні каруселі з товарами. Всі компоненти побудовані з урахуванням принципів доступності (accessibility) та адаптивного дизайну.

## ✨ Функціональність

### Головна сторінка (`index.html`)

- **Hero-секція** з основним заголовком та призивом до дії
- **Промо-банери** для реклами акцій та спеціальних пропозицій
- **Карусель тварин** з категоріями домашніх улюбленців
- **Секція безпеки** з інформацією про гарантії та надійність
- **Карусель трендових товарів** з популярними продуктами
- **Секція промоцій** з акційними пропозиціями
- **Карусель нових надходжень** з останніми товарами
- **Відео-промо** для демонстрації продукції
- **Відгуки клієнтів** (testimonials) з рейтингами та коментарями
- **Каталог кормів** з різноманітними видами кормів для тварин

### Сторінка продукту (`homepage.html`)

- **Галерея зображень** з можливістю перегляду та навігації між фото
- **Детальна інформація про продукт**:
  - Назва та код продукту
  - Ціна та статус наявності
  - Опис товару
- **Керування кількістю** товару з інтерактивними кнопками
- **Додавання до кошика** з миттєвим оновленням

### Кошик покупок

- **Модальне вікно кошика** з повною інформацією про товари
- **Додавання/видалення товарів** з кошика
- **Оновлення кількості** товарів без перезавантаження сторінки
- **Відображення загальної суми** замовлення

## 🛠 Технології

Проєкт побудований на сучасному технологічному стеку:

- **HTML5** — семантична розмітка та структура сторінок
- **CSS3** — стилізація компонентів, адаптивний дизайн, CSS Grid та Flexbox
- **JavaScript (ES6+)** — інтерактивність, обробка подій та логіка додатку

- **HTMX 1.9.10** — динамічне завантаження контенту без перезавантаження сторінки
- **Google Fonts** — типографіка:
  - PT Sans (основний текст)
  - Baloo 2 (заголовки та акценти)

## 🚀 Встановлення та запуск

### Передумови

Для запуску проєкту необхідно мати один з наступних інструментів:

- **Python 3.x** (для вбудованого HTTP сервера)
- **Node.js** (для http-server або інших статичних серверів)
- Або будь-який інший локальний веб-сервер

### Крок 1: Клонування репозиторію

```bash
git clone <repository-url>
cd pets-store
```

### Крок 2: Запуск локального сервера

#### Варіант 1: Python (рекомендовано)

```bash
# Python 3
python -m http.server 8000

# Або Python 2 (якщо використовується)
python -m SimpleHTTPServer 8000
```

#### Варіант 2: Node.js (http-server)

```bash
# Встановлення http-server глобально (якщо ще не встановлено)
npm install -g http-server

# Запуск сервера
http-server -p 8000
```

#### Варіант 3: Node.js (npx, без встановлення)

```bash
npx http-server -p 8000
```

#### Варіант 4: PHP (якщо встановлено)

```bash
php -S localhost:8000
```

### Крок 3: Відкриття в браузері

Після запуску сервера відкрийте браузер і перейдіть за адресою:

```
http://localhost:8000
```

**Важливо:** Для коректної роботи HTMX та завантаження partial компонентів необхідно використовувати локальний сервер. Відкриття файлу `index.html` напряму через `file://` може призвести до помилок через обмеження CORS.

## 💻 Використання

### Навігація по сайту

1. **Головна сторінка** (`index.html`) — початкова сторінка з каталогом товарів та різноманітними секціями
2. **Сторінка продукту** (`homepage.html`) — детальна інформація про конкретний товар

### Робота з кошиком

- Натисніть на іконку кошика в правому верхньому куті для відкриття модального вікна

- Змінюйте кількість товарів безпосередньо в кошику
- Видаляйте товари, натискаючи на відповідну кнопку

### Перегляд продуктів

- Використовуйте каруселі для перегляду різних категорій товарів
- Натискайте на товари для переходу на сторінку з детальною інформацією
- Переглядайте галерею зображень на сторінці продукту

## 📁 Структура проєкту

```
pets-store/
├── api/                          # API дані (JSON)
│   └── product.json              # Дані про продукти
├── assets/                       # Статичні ресурси
│   └── img/                      # Зображення
│       ├── carousel/             # Зображення для каруселі тварин
│       ├── trending-carousel/    # Зображення трендових товарів
│       ├── arrivals-carousel/    # Зображення нових надходжень
│       ├── food/                 # Зображення кормів
│       ├── homepage-promotions/  # Промо-зображення
│       ├── testimonials/         # Фото клієнтів
│       ├── video-promo/          # Зображення для відео-промо
│       ├── favicon.png           # Іконка сайту
│       └── logo.svg              # Логотип
├── css/                          # Стилі компонентів
│   ├── global.css                # Глобальні стилі
│   ├── global.cart.css           # Стилі кошика
│   ├── global.footer.css         # Стилі футера
│   ├── global.header-nav.css     # Стилі навігації
│   ├── index.css                 # Стилі головної сторінки
│   ├── homepage.css              # Стилі сторінки продукту
│   └── index.*.css               # Стилі окремих секцій
├── js/                           # JavaScript модулі
│   ├── index.js                  # Основний скрипт головної сторінки
│   ├── homepage.js               # Скрипт сторінки продукту
│   ├── global.cart.js            # Логіка кошика
│   ├── global.forms-footer.js    # Обробка форм у футері
│   └── index.*.js                # Скрипти для окремих секцій
├── *.partial.html                # Часткові HTML компоненти
│   ├── global.*.partial.html     # Глобальні компоненти (header, footer, cart)
│   └── index.*.partial.html      # Компоненти головної сторінки
├── index.html                    # Головна сторінка
├── homepage.html                 # Сторінка продукту
└── README.md                     # Документація проєкту
```

### Основні файли

- **`index.html`** — головна сторінка магазину з усіма секціями
- **`homepage.html`** — сторінка з детальною інформацією про продукт
- **`*.partial.html`** — перевикористовувані HTML компоненти, які завантажуються динамічно через HTMX
- **`api/product.json`** — JSON файл з даними про продукти

## 🎯 Особливості реалізації

### Модульна архітектура

Проєкт використовує модульний підхід до розробки:

- **Partial HTML компоненти** — перевикористовувані блоки коду, які завантажуються динамічно
- **Модульні CSS файли** — окремі файли стилів для кожного компонента
- **ES6 модулі JavaScript** — організація коду у логічні модулі

### HTMX для динамічного контенту

Використання HTMX дозволяє:

- Завантажувати контент без перезавантаження сторінки
- Покращити користувацький досвід завдяки швидшому відгуку інтерфейсу
- Зменшити навантаження на сервер завдяки частковому оновленню DOM

### Адаптивний дизайн

Проєкт повністю адаптивний та коректно відображається на:

- Десктопних пристроях (1920px+)
- Планшетах (768px — 1024px)
- Мобільних пристроях (320px — 767px)

### Доступність (Accessibility)

Реалізовано підтримку доступності:

- **ARIA атрибути** для кращої підтримки скрін-рідерів
- **Семантична HTML розмітка** для коректної структури сторінок
- **Клавіатурна навігація** для всіх інтерактивних елементів
- **Альтернативний текст** для всіх зображень
